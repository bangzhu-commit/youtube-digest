YouTube Digest

Bring your own API keys

Keys stay in this Chrome profile and are sent only to Supadata and DeepSeek. This open-source extension has no developer server or analytics.

Transcript provider

Read the current video's native captions or transcript. May open YouTube's transcript panel. No speech transcription is performed.

Used to fetch timestamped YouTube subtitles. Create a Supadata account and key. Supadata generates the key during onboarding.

AI provider

Enter the exact model ID from your provider. Select a chat model that supports JSON output.

Reviewed mode uses two model calls per batch. Quick mode uses one. New translations are cached separately.
