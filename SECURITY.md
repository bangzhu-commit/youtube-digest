# Security: local modified version

Install from the reviewed local source directory. Preserve the original MIT license, the adapted translation rules' third-party notice, and verify updates before reloading.

Enter keys only in the extension Settings. Never include them in source, chat, logs, screenshots or commits. Keys for OpenRouter, 302.ai and DeepSeek are separate and switching platforms does not reuse a different platform's key. Native caption extraction receives only the video ID, never credentials. API requests are made by the extension's trusted service worker to fixed provider endpoints.

Use provider spending limits. Native-only mode cannot charge Supadata; automatic fallback is explicitly selected. Translation and AI overview use the selected provider's API balance, or Codex subscription entitlement when local Codex is selected. No account creation, purchase or cloud publication is performed by this copy.

The optional host is registered for exactly one extension ID and one chosen vault. Its bounded protocol accepts episode-scoped loads, saves, transcription start/status/cancel, at-most-ninety-second clips and bounded Codex text requests. It accepts no arbitrary path, shell command or download URL. Download URLs are resolved from a fixed public episode page; exact hosts and redirects are checked, with size/time limits and private-address rejection. Explicit local Fake-IP compatibility permits only the benchmark 198.18.0.0/15 range for those fixed HTTPS hosts, retaining TLS verification; loopback and other private targets remain blocked. Jobs are deduplicated and checkpoints persist. FFmpeg accepts local media protocols only; Whisper loads cached models. Symlinks outside the vault are rejected. Sources and manually edited derivatives are preserved, saves are deduplicated, and derivatives bind to source hashes. Keep private configuration outside the repository. Rerun the installer after upgrading or changing source folder or extension ID.

Only the trusted podcast panel can request file/transcription operations. Codex processing is restricted to trusted extension pages, requires existing ChatGPT login, disables tool execution, and never falls back to API-key billing. Inputs are text to process, not executable instructions. The CLI, subscription and login remain user-managed.

The release script checks syntax, tests, manifest references, package allowlist and potential secrets. This does not establish every provider's live behavior. Run npm test, npm run check, npm run package and test a real public captioned video and a Xiaoyuzhou episode after installation.
