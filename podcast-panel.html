文字精校与摘要使用设置中选择的服务。

使用本集音频区分声音，只标编号，不猜身份。需已配置本机识别组件，不会自动下载安装。

可选：疑难段落听音复核

听音复核与整集转写、文字精校分开。此功能需在设置中选择 OpenRouter 并配置 API Key，会先用本地 Whisper 转写，再把最多 90 秒音频交给所选 Gemini 模型，另外按服务价格计费。整集转写完成后会保留本地原音频。

点击“转写整集”，用本地 Whisper 将本集音频转成带时间戳的全文。长节目需要等待，关闭侧栏后仍会继续。也可以读取素材库或导入已有文稿；节目简介不会作为全文。

概览由设置中的文字模型根据全文生成，可能有误；引用请核对原文。生成结果会保存在本机，并随 Markdown 导出。
